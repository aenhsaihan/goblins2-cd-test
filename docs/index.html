1. Bring your CD game

This test supports the English US CD v1.000 release. Import Gobliins_2_CD_ready.zip, prepared from your supplied disc bundle, or its extracted folder. It includes the game data and the complete CD audio in browser-compatible Ogg Vorbis format. The original 444 MB ZIP, raw disc image and FLAC file cannot be imported directly here.

2. Make yourself at home

  • On iPhone, use Safari → Share → Add to Home Screen, then rotate to landscape.
  • Drag to move the pointer; tap to click. Two-finger tap is the right mouse button. A mouse and keyboard work too.
  • Move the pointer to the top edge for the game's menu; the floppy-disk icon opens Save/Load. Use Keyboard for a save name: type the name and Return, then tap the green check. CD saves are separate from the floppy edition and Goblins 3.
  • Tap Sound if audio needs waking up. The small Menu button returns here without restarting the game.

Files are never sent to a server. Browser storage can still be cleared by the device or its settings; don't rely on private browsing to keep saves.
